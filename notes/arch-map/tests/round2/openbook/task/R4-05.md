A change allowed the two_phase option of a subscription to be altered. Because the option is controlled by both the publisher (as a slot option) and the subscriber, the slot option must also be modified. Turning it from true to false is permitted only when there are no pending prepared transactions for the subscription, since otherwise their changes could be replicated again along with the commit, giving duplicate data or errors. Turning it from false to true is allowed only after initial data synchronization is complete, so it is performed later by the logical replication worker.
