A recent change converted all remaining built-in subsystems to a new shared-memory allocation API. Its stated goal was to remove every remaining direct use of the older routines that create or attach to named shared structures and shared hash tables in built-in code. After this conversion, subsystems set up their shared state through registered callbacks instead. Consider a build where each server child process is started by re-executing the server binary (the EXEC_BACKEND model, as on Windows) and the debugging GUC wal_debug is turned on.
